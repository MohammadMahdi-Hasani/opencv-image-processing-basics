# Image Processing Basics with OpenCV

## Overview
A beginner-friendly project exploring fundamental image processing techniques using Python, OpenCV, NumPy, and Matplotlib.

## Topics Covered
- Loading and displaying images
- Accessing and modifying pixel values
- Region of Interest (ROI)
- Image visualization with Matplotlib
- Image border padding techniques

## Technologies
- Python 3.9
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## Installation

```bash
pip install -r requirements.txt
jupyter notebook
```

Place `Camman256B.bmp` and `Birds.bmp` in the expected image directory before running the notebook.
